## 🧠 About the Project

**REDACT** is an AI-powered application designed to automatically **detect** and **redact sensitive information** from documents across various formats. Whether it's **personal identifiers**, **financial records**, or **confidential terms**, REDACT ensures **data privacy**, **compliance**, and **security** using advanced **ML, NLP**, and **blockchain** integrations.

> 🔐 Your privacy. Our priority.

## 🚀 Key Features

- 🔍 **Automated Redaction**: AI detects sensitive entities & replaces them intelligently.
- 📄 **Multi-Format Support**: Works with PDFs, DOCX, XLSX, and TXT files.
- ⚙️ **Custom Rules**: Add regex/keyword-based redaction logic.
- 🧑‍💻 **User-Friendly UI**: Clean and modern web interface.
- 📂 **Batch Processing**: Upload and redact multiple files at once.
- 📑 **Audit Trail**: Maintain detailed logs for compliance & transparency.
- 🔗 **Blockchain-Backed**: Immutable proof of redaction via **Polygon + IPFS**.

## ⚙️ Setup Instructions
1.	Clone the Repository
 ```bash
git clone https://github.com/SachinChandra2022/RE-DACT.git
cd REDACT
```
2.	Install Backend Dependencies
 ```bash
cd backend
pip install -r requirements.txt
```
3.	Run Frontend
 ```bash
cd ../frontend
npm install
npm run dev
```
